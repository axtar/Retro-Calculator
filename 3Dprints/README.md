# Printing the case

### Print area
The required print area is 240mm x 210mm.

### Used material
PLA

## Support enforcers
Add the green enforcers when priting the base case part.
![Enforcers](Images/enforcers.png)

### Notes
- The driver spacers are not needed for the IN-17 display.
- The led board spacer is only needed for the IN-16, IV-8 and IV-9 displays.
- Print only the frame for the display being used.
