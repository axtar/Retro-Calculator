# Gerber and EasyEDA project files

> [!WARNING]
> ### Please note that the Gerber files have been regenerated and are untested.
If you use the EasyEDA project files you can make changes and generate your own Gerber files. The files can be imported into EasyEDA PRO or Kicad and continue from there.<br>

The case has been designed for 1.6mm boards. For this project I recommend ENIG black for the label board and lead-free (RoHS) black for the other boards. Black boards look better behind the acrylic panel.
